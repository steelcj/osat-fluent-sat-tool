# Markdown: No Horizontal Rules

Version: 0.3.1
Status: Draft
Style Guide: style-guide--versioned-documents-in-unrendered-markdown

## The rule

Do not use horizontal rules in the content of markdown documents without asking and obtaining permission first. The frontmatter delimiters (`---` opening and closing the YAML block) are not horizontal rules and are always permitted.
