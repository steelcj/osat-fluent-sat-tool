# Markdown: No Heading Numbers

Version: 0.4.1
Status: Draft
Style Guide: style-guide--versioned-documents-in-unrendered-markdown

## The rule

Do not number headings in markdown documents unless explicitly asked. Numbered headings conflict with content that has its own numbering system, such as article series, chapters, or parts. If numbered headings would genuinely aid navigation in a specific document, ask before adding them.
